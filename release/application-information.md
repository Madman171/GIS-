## 三、软件功能简介

本软件面向 GIS 交通路网课程教学，将课程模块、知识点及其前置、相关、
组成部分等关系组织为知识图谱。系统提供完整知识目录、模块总览图、
知识点展开、知识点详情、视频和 PPT 资源扩展、全文目录搜索以及基于
DeepSeek API 的智能问答功能。用户可以从模块进入知识点，查看属性、
难度、重要性和关联知识，人工智能问答会结合当前图谱上下文回答，
并返回可供继续查看的相关知识点。

## 四、主要技术特点

1. 使用 Neo4j 属性图模型存储教学知识结构。
2. 使用 D3.js 实现模块和知识点力导向图。
3. 使用 Vue 3 实现三栏式交互界面。
4. 使用 FastAPI 提供参数化只读查询接口。
5. 使用 DeepSeek API 实现知识图谱增强问答。
6. 使用独立媒体目录和 `HAS_MEDIA` 关系扩展教学视频及课件。
7. 提供数据库快照、自动化测试和软著源码整理脚本。
