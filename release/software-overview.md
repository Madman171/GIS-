# 软件概述

## 一、软件名称

GIS交通路网教学知识图谱平台 V1.0

## 二、开发目的

本软件用于整理和展示 GIS 交通路网课程知识结构，解决传统章节列表难以
表达知识点之间多关系的问题，为教学展示、知识检索和智能答疑提供统一平台。

## 三、主要功能

| 功能 | 说明 |
| --- | --- |
| 知识目录 | 展示九个模块及全部知识点 |
| 模块总览 | 以力导向图展示模块及模块间关系 |
| 知识点展开 | 展示模块下知识点和内部关系 |
| 知识点详情 | 展示说明、难度、重要性、分类和关联知识 |
| 媒体资源 | 支持视频、PDF、PPT、PPTX 扩展 |
| 智能问答 | 基于图谱上下文调用 DeepSeek |
| 引用跳转 | 回答可以关联并跳转知识点 |
| 数据导出 | 支持节点、关系和数据库快照导出 |

## 四、软件结构

```text
知识图谱网页平台
├── 知识目录
├── 图谱可视化
├── 知识点详情
├── 教学媒体
└── 智能问答
```

## 五、技术路线

1. Neo4j 保存教学知识图谱。
2. FastAPI 提供数据查询和业务接口。
3. Vue 3 和 D3.js 实现页面和图形交互。
4. DeepSeek API 提供自然语言回答。
5. 参数化只读查询保证数据访问安全。

## 六、软件特点

1. 面向 GIS 交通路网教学场景。
2. 模块、知识点和关系分层展示。
3. 支持知识点前置和相关关系。
4. 支持教学视频和课件扩展。
5. 智能问答基于图谱上下文，不直接执行模型生成的 Cypher。
6. 数据库结构、快照和测试材料可复现。
