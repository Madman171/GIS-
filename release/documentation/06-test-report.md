## 四、后端测试明细

执行命令：

```powershell
cd E:\gis-knowledge-platform\backend
.\.venv\Scripts\python.exe -m pytest `
  --cov=main `
  --cov=deepseek_service `
  --cov=config `
  --cov-report=term-missing
```

测试内容：

1. `/api/health` 返回数据库连接正常。
2. 目录返回 9 个模块和 344 个知识点。
3. M1 返回 38 个知识点、39 个节点和 56 条关系。
4. 知识点 `M1-001` 可以返回节点、模块和媒体数组。
5. 不存在的知识点返回 HTTP 404。
6. 搜索接口能够返回匹配结果。
7. 未配置 DeepSeek Key 时，状态正确降级。
8. 未配置 DeepSeek Key 时，问答接口返回 HTTP 503。
9. 问答接口会构建真实图谱上下文。
10. DeepSeek 上游异常时返回 HTTP 502。
11. 数据快照节点和关系统计正确。
12. 数据快照不存在重复业务主键。
13. 所有关系端点均能匹配到对应节点。
14. 关系类型集合与冻结版本一致。
15. 合法视频媒体可以通过导入校验。
16. 非法路径和不支持的文件扩展名会被拒绝。
17. 超过每分钟提问限制时返回 HTTP 429。

实际结果：

```text
11 passed, 6 skipped in 4.29s
TOTAL coverage: 41%
```

Neo4j 运行时可执行全部 17 项测试；本机数据库离线时会自动跳过 6 项
数据库集成测试，其他接口、问答、限流、快照和媒体逻辑仍会执行。

## 六、真实 DeepSeek 联调

开发过程中已经完成真实 API 联调：

1. `/api/chat/status` 返回 `configured: true`。
2. 基于当前知识点提问正常返回中文回答。
3. 根据“轨迹数据有哪些关键技术”等问题搜索相关节点。
4. 回答返回相关知识点引用。
5. 网页状态显示“已连接”。
6. 点击引用可以打开对应知识点详情。

自动化测试默认模拟 DeepSeek 响应，避免每次执行测试产生 API 费用。

## 七、测试限制

1. 当前测试主要面向单用户本地教学环境。
2. 尚未进行多用户并发和压力测试。
3. 尚未执行长时间运行稳定性测试。
4. DeepSeek 模型输出存在正常波动，可通过固定测试提示词和模拟响应保证测试可重复。
