# 软件版本基线

## 基本信息

| 项目 | 内容 |
| --- | --- |
| 正式名称 | GIS交通路网教学知识图谱平台 |
| 正式简称 | GIS知识图谱平台 |
| 版本号 | V1.0 |
| 内部项目名 | gis-knowledge-platform |
| 软件类型 | 教学知识图谱可视化 Web 平台 |

## 项目用途

本软件面向 GIS 交通路网相关课程，提供知识图谱目录浏览、模块与知识点可视化、
知识点详情展示、教学资源扩展和智能问答扩展能力。

## 技术栈

| 层级 | 技术 |
| --- | --- |
| 前端 | Vue 3、Vite、Axios、D3.js |
| 后端 | Python、FastAPI、Neo4j Python Driver |
| 数据库 | Neo4j |
| 智能问答 | DeepSeek API，通过本地环境变量配置启用 |

## 命名规则

以下位置必须使用统一名称和版本：

1. 网页标题与页面品牌区。
2. 后端 OpenAPI 标题与版本。
3. 前端 `package.json`。
4. 系统设计说明书。
5. 操作手册、测试报告和部署说明。
6. 软著源码整理件的页眉与封面。

## 版本说明

V1.0 的核心功能定位为：

1. 完整知识目录。
2. 模块总览图。
3. 模块知识点展开。
4. 知识点详情。
5. 视频与 PPT 资源扩展接口。
6. 智能问答界面与后端扩展接口。
