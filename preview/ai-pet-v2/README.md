# Spirit Pix V2 preview

This directory contains the standalone preview for the AI pet redesign. It is
not wired into the production frontend and is not part of a deployment.

Files:

- `spirit_pix_v2.blend` — editable Blender 5.2 source.
- `spirit_pix_v2.glb` — Draco-compressed web asset.
- `spirit_pix_v2-preview.png` — white-background approval render.
- `validation-report.md` — export and compatibility checks.

The model follows the supplied reference plate: large layered blue bob, peach
face, navy eyes with blue highlights, pointed ears, powder-blue romper, short
limbs, chunky blue boots, four translucent wings, and small aqua motes.
