# 六关学习闯关

本功能把GIS入门知识、练习及章节考试连接到现有交通路网知识图谱。六关共54道原创教学题，每关4道练习、5道章节考试；题干、答案、解释及直接依据来自本轮已核查题库1.0.1。自拟道路、速度、耗时及阈值均为教学假设。

## 学生流程

从网站顶部“学习闯关”进入，或直接打开 `/#learn`。

1. 阅读本关知识讲解，可打开对应知识点弹窗，关闭后继续学习。
2. 完成4道练习。每题提交后显示正确答案、解析、错误选项说明和可展开的权威依据。
3. 完成5道章节考试后统一交卷，每题20分，80分通过。未交卷时不显示答案；通过后解锁下一关，可反复回顾或重新考试。
4. 学习进度、练习答案、考试草稿、最近成绩和最高成绩保存在当前浏览器。刷新或切回图谱后可继续。通过后重考失利不会取消已通过状态。

图谱阅读独立保留，实践任务仍未加入。本轮是匿名自学功能，不包含学生账户、跨设备同步或教师成绩册；本机成绩不作为经过身份核验的正式考试记录。

## 内容与判题

运行时题库为 [learning-bank.json](../backend/content/learning-bank.json)。知识点名称与修订后的快照一致，16个相关知识点的澄清内容同时进入本次发布。原始核查清单见 [knowledge-clarifications-2026-11-02.md](knowledge-clarifications-2026-11-02.md)。

- 单选严格匹配选项；多选按完整集合匹配，顺序不影响结果，多选、少选及错选均不得分。
- 判断题使用布尔类型，`false`不等于未作答、数字0或字符串`"false"`。
- 数值题使用指定单位，按题库中的绝对容差判定，并包含误差边界。服务端以Decimal解析，再用精确有理数比较误差，拒绝NaN、无穷、表达式或带不明单位的值。
- 路线及计算题沿用逐题核查后的答案；浏览器测试覆盖所有54题、考试不通过与重试、解锁和刷新恢复。

答案和判题在服务端，公开题目接口不包含标准答案、解析、复算预期值或最优路径集合。练习提交仅接受本关练习题ID；考试必须提交本关完整5题。接口不记录身份或运行数据库成绩。

## 接口

| 方法与路径 | 功能 |
| --- | --- |
| GET `/api/learning/chapters` | 六关目录、前置关卡、题量、通过线及内容版本 |
| GET `/api/learning/chapters/{chapter_id}` | 本关讲解、知识点和不含答案的题目 |
| POST `/api/learning/chapters/{chapter_id}/practice` | 提交`question_id`与`answer`，返回本题结果及解释 |
| POST `/api/learning/chapters/{chapter_id}/exam` | 提交以本关5个题号为键的`answers`，返回分数及完整回顾 |

题库作为后端镜像中的只读内容随版本发布，不依赖Neo4j保存题目。知识图谱依旧使用Neo4j；已澄清的知识点需在部署时按现有初始化/导入流程同步。

## 设计与验证

按design-taste-frontend的app-screen流程实施，采用 **Editorial greeting，seed 633635674**，保留现有Noto Sans SC、Noto Serif SC及蓝灰色体系，使用平面分层和可阅读的题目表单。没有更换整站框架、引入新图标库或新增外部图片。小迪使用项目中已确认的二维图像。

页面的主要问题是“我现在学什么、下一步做什么”；六个前置知识阶段成为连续的学习路线。题目是界面的主要内容，颜色只用于当前选择、进度和判题状态。

通过后端判题测试、现有图谱回归测试及前端键盘/手机/保存失败/网络重试测试；另在生产构建上连接真实判题后端跑通六关54题。视觉检查使用1440、768、390三种宽度。详细图片、检查结果及设计自评保存在本轮发布artifacts中；部署是否成功以最终生产验证记录为准。
