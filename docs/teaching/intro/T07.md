# 路线的成本是什么：先定目标，再累加同类数值

## 为什么要给道路一个数？

比较可行路线时，需要说明什么叫“更好”。若目标是总里程最短，就用路段长度作为边权；若目标是时间最少，就用适用的行驶时间。边权是附在边上的成本数值，本课也把需要最小化的行程成本称为阻抗。它不是道路难度的固定标签，而是任务中选定的比较依据。[S14]

下面只考虑图示四条有向边，各边在本次计算中固定，均允许本题车辆通行且无额外转向限制。数字是给定沿道路长度，单位统一为千米，不代表真实调查。

![从S到T的两条路线，S到A和A到T各3千米，S到B为2千米，B到T为5千米](/assets/teaching/intro/distance-network.svg)

S→A→T长3+3=6千米；S→B→T长2+5=7千米。因此在本题全部合法候选中，距离目标应选前者。不能因为S→B这一段较短，就认定经B的整条路线最短。

## 单位与累加范围要明确

600米、0.9千米和500米需要先统一单位，才能得到0.6+0.9+0.5=2千米。若路线真的重复经过某段，通常应按经过次数计入里程；本课具体计算以题目给出的路线和次数为准。

距离和时间不是同一种量。没有事先定义综合评分公式时，不能把“2千米+3分钟”直接说成“5分钟”。即使将来使用多指标模型，也必须交代转换、权重和含义；本讲只比较单位一致、可相加的成本。

还有一点：只能先在允许的路线中比较成本。禁止通行的路段不会因为长度短就变成可用，路网限制与成本排序要分别处理。[S15]

## 自测

只有两条合法候选路线：甲由0.7千米和800米组成，乙全程1.6千米。按距离目标选哪条？如果只知道这些长度，能否确定时间目标也选同一条？

## 自测答案与解析

甲为0.7+0.8=1.5千米，小于乙的1.6千米，距离目标选甲。还不能确定时间目标，因为缺少适用速率或时间成本及其他延误条件。比较标准改变后，应使用相应成本重新判断。
