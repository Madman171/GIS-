# 单向道路：有连接，也要沿允许的方向走

## 箭头是一条通行条件

两处之间存在道路，不代表两个方向都允许。本课用有向边U→V表达仅允许从U到V的方向；若还允许反向，需要另有反向边或明确的双向约定。不同软件的存储方式可以不同，这里采用给定有向图，不把符号当成某个数据文件的固定编码。[S20][S13]

把路线写成节点顺序之后，要逐边检查。例如本题只有P→Q、Q→R、R→P三条边，均允许本题车辆使用，连接处转向均允许。从Q到P可以依次经过Q→R→P，但不能直接使用Q→P，因为题目没有那条边。

![有向环P到Q到R到P，反向边不能自行补出](/assets/teaching/intro/direction.svg)

这个例子说明，“没有直接反向边”不等于“全网绝对无法反向到达”。能否绕行，要看其他给定边及相关限制。检查到某一段不允许时，应否定当前序列；若问题问有没有别的路线，还需继续查找，不能提前把全网判成不可达。

## 数据方向不靠猜

实际道路资料可能通过字段和编码描述单向或双向。应阅读该数据的定义，明确“沿数字化方向”和“逆数字化方向”的含义。路名、线条颜色或你从左向右阅读的习惯，都不能替代方向字段。连接确认后，车辆类型和指定转向等限制也仍要检查。[S15]

## 自测

只给出X→Y、Y→Z、Z→X三条边，其他转向与使用条件均允许。下面两个序列从Y出发，哪个可以到X：Y→X，还是Y→Z→X？如果删去Z→X且没有别的边，还能到X吗？

## 自测答案与解析

Y→Z→X的每一段都存在，故可行；直接Y→X不存在。删去Z→X后，从Y只能到Z，不能到X。两个结论的依据不同：先前只是缺少直接边，删边后才在这个明确限定的局部网络中没有可行路线。
