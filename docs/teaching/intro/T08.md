# 从千米到分钟：把行驶时间算清楚

## 长度不能直接当作耗时

给你一条长1.8千米的路，能否马上知道要走几分钟？还不能。至少要知道适用的行驶速率，并说明是否计入等待、转向或停车等时间。即使路线相同，条件改变后耗时也可能不同。

本课先用简化模型：每段平均行驶速率在本次计算中固定且大于零，给定路段长度可信；各段行驶时间与明确列出的额外延误可以相加。所有道路、速率与延误都是教学假设，不是对真实出行的预测。[S14][S22]

## 分清公式中的单位

在这个模型下，行驶时间=路段长度÷平均行驶速率。如果长度用千米，速率用千米/小时，所得时间就是小时，换成分钟还要乘60。不要算出0.05小时后直接写成0.05分钟。

例如1.8千米÷36千米/小时=0.05小时，即3分钟。若整段行程另有且仅有一次0.4分钟等待，总时间为3+0.4=3.4分钟。等待没有因为路线包含两个端点就自动变成两次，必须按题目指定的次数计入。

| 量 | 本课写法 | 检查重点 |
|---|---|---|
| 长度 | 千米或米 | 先统一单位 |
| 平均行驶速率 | 千米/小时等 | 与长度、时间单位配套，且本模型中大于零 |
| 行驶时间 | 长度÷速率 | 确认结果是小时还是分钟 |
| 总行程时间 | 各段行驶时间＋明确给出的延误 | 不漏算，也不重复计算 |

## 多段道路，应当逐段计算

假设连续两段路各长1千米，平均速率分别为20和40千米/小时，不计其他延误。第一段需1÷20×60=3分钟，第二段需1÷40×60=1.5分钟，总计4.5分钟。

如果简单把两个速率平均成30，再算2÷30×60，会得到4分钟，和逐段结果不一致。问题在于两段路所花的时间不同，速率不能在未说明条件时直接作算术平均。入门阶段最稳妥的办法是逐段求时间，再累加；不要为省一步计算更换了模型。[S22]

还要区分平均运行速率与道路限速。限速不是车辆每次行驶都能保持的平均速率；真实行程会受到交通状况和等待等因素影响。只有限速信息时，不能把据此算出的一个数承诺为实际耗时。本课使用的是题目明确给出的平均行驶速率。[CN01]

## 最短和最快为什么可能不同？

沿用距离讲解中的两条候选路线：S→A→T为6千米，S→B→T为7千米。现在额外给定：前者各段平均速率都为30千米/小时，后者各段都为70千米/小时，均合法，不计任何其他延误。

前者需6÷30×60=12分钟，后者需7÷70×60=6分钟。距离目标选经A，时间目标则选经B。这不是两道计算互相矛盾，而是优化的成本不同。[S14]

**引导解析：** 不可以。可行性条件满足后，应按新的时间成本重新比较；原先距离最短的结论不保证时间也最少。

## 自测

### 1. 单段换算

一段路长2千米，固定平均速率为30千米/小时，不计延误，需要几分钟？

### 2. 逐段累加

两段连续道路分别长0.6、1.4千米，平均速率分别为18、42千米/小时；整条路线另有且仅有一次0.8分钟等待，不计其他延误。总时间是多少？

### 3. 资料和模型的边界

只有道路限速，没有平均行驶速率和等待资料，能否保证一个精确到分钟的实际耗时？如果题目给的平均速率为零，能否直接继续使用长度÷速率？

## 自测答案与解析

1. 2÷30小时=1/15小时，乘60得到4分钟。
2. 第一段0.6÷18×60=2分钟，第二段1.4÷42×60=2分钟，再加一次0.8分钟，总计4.8分钟。单位已统一，等待只计一次。
3. 不能保证。需要适当的运行时间模型和相关条件；限速不是测得的平均运行速率。速率为零时不能除以零，应重新确认是否等待、封闭或需要其他时间模型，而不是硬算有限行驶时间。
