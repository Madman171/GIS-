# 路网检查：尽端路不一定是数据错误

## 先问本来应不应该连接

拓扑检查用于发现不符合所选规则的数据情况，例如本来应该相接的道路留下小缝隙。但检查标记只是需要核实的线索，不等于每一处都应使用同一种修复方法。规则必须结合真实道路和数据规范解释。[S28]

设想两种情况：甲处是实际存在的尽端路，只有一条道路接入；乙处是现场确实连通的普通路口，但数字化时少画了一小段。两处在图上都可能出现线的端点，处理却不同。甲应保留真实尽端结构，乙才需要调查遗漏并正确表达连接。[S12]

![合法尽端、非预期断裂与不能误接的跨层道路对照](/assets/teaching/intro/topology-check.svg)

## 为什么不能把所有端点接起来？

有些检查规则要求线不出现悬挂端点。这里的悬挂，是端点没有与其他适用线连接的情况；真实尽端路可能属于应记录的合法例外。若为了消除标记，把尽端路拉到附近道路上，就会制造现场并不存在的连接。[S12][S28]

同样，距离近也不等于应该连接。桥上桥下、隔离设施两侧或平行道路不能仅因位置靠近就被误接。操作前保留原数据，核对道路设施和规范；操作后再检查连接、几何与相关属性是否仍正确。具体捕捉容差和处理工具属于后续实操，本讲先建立核实意识。[S11]

## 自测

路网检查标记了三个位置：①现场确认的真实尽端路；②现场应连通但数据留有缝隙的路口；③没有转换设施的上下跨越道路。应该把哪一处列为连接修正的候选？另外两处为什么不能一律拉线接上？

## 自测答案与解析

②是连接修正的候选，仍需按资料与规范确认处理方式。①应保留真实尽端结构，并按采用的检查规范记录例外；③没有该处转换连接，不能凭几何位置制造连接。检查的目标是准确表达道路，不是把所有标记机械清零。
