## 来源与事实审校

来源索引见[SOURCES.md](SOURCES.md)。正文引用和网站“查阅依据”链接均指向官方文档、公开教材或高校原始教学资料，未以搜索摘要或AI回答作为唯一依据。沿用题库来源编号；M1-015保留其独立的S1–S4编号，避免误认成同一索引。

原题库已核对来源的访问日期保持原记录；本批复查不将所有日期统一改写为今天。样章原有来源已于2026-11-05核对。原始资料中的软件实现仅用于支持概念，不规定所有GIS必须采用同一建网方式。教学图和数字是原创教学设定，不是真实道路资料。

重点交叉检查：

- T02：QGIS投影说明、重投影说明与Esri Define Projection支持“指定不改变原坐标”；QGIS测量说明单独核对椭球及单位，避免把屏幕叠加或项目单位当成测量保证。
- T04／T06：Esri连接与转向文档分别核对网络连接及特定动作限制；Esri拓扑规则和QGIS拓扑资料核对真实尽端的合法例外。
- T08：成本属性与公开教材交叉检查长度／平均速率的量纲；限速与平均行驶速率分开，不提出真实道路限速建议。
- T09：NetworkX官方文档与MIT算法课程资料独立支持非负条件、累计暂定值与单终点停止时机。并列最优路线不作为错误答案排除。
- T10：Esri限制、障碍和历史交通资料分别支持禁用、成本与时间情景；固定情景的简化条件逐次明示。

本批未改原知识摘要，未发现必须改动现有54题答案才能上线的冲突。较宽泛节点的高阶内容仍待后续教学，不标记为全部掌握。
